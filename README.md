# งบประมาณประจำปี — Waterfall Chart

เว็บแอพแสดงกราฟ waterfall จากข้อมูลแผนงบประมาณรายปีของบริษัท (ตัวเลขจำลอง หน่วย: ล้านบาท)
ไล่จากรายได้รวม หักค่าใช้จ่ายแต่ละหมวด จนถึงกำไรสุทธิ

## วิธีใช้งาน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย — เป็นไฟล์เดียวจบ ไม่ต้องติดตั้งอะไร
(HTML + CSS + JavaScript ล้วน วาดกราฟด้วย SVG ไม่พึ่ง library ภายนอก)

หรือเสิร์ฟผ่านเว็บเซิร์ฟเวอร์:

```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

## ฟีเจอร์

- กราฟ waterfall: รายได้รวม → หักค่าใช้จ่ายรายหมวด → กำไรสุทธิ พร้อมเส้นเชื่อมระหว่างแท่ง
- เลือกปีงบประมาณได้ (พ.ศ. 2567 / 2568 / 2569)
- การ์ดสรุป: รายได้รวม ค่าใช้จ่ายรวม กำไรสุทธิ (พร้อม % เทียบปีก่อน) และอัตรากำไรสุทธิ
- tooltip แสดงจำนวนและยอดสะสมเมื่อชี้ที่แท่ง
- สลับมุมมองกราฟ / ตารางข้อมูล
- รองรับโหมดสว่าง/มืด (ตามระบบ หรือกดปุ่มสลับเอง)
- สีผ่านการตรวจสอบสำหรับผู้มีภาวะตาบอดสี (น้ำเงิน = เพิ่มขึ้น, แดง = ลดลง, เทา = ยอดรวม)

## แก้ไขข้อมูล

ข้อมูลอยู่ในตัวแปร `BUDGETS` ใน `index.html` — เพิ่มปีหรือแก้รายการได้โดยตรง:

```js
"2570": [
  { label: "รายได้รวม", value: 135, kind: "start" },
  { label: "ต้นทุนขาย", value: -52, kind: "delta" },
  // ...
  { label: "กำไรสุทธิ", kind: "end" },  // คำนวณอัตโนมัติ
],
```
